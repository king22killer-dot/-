# 夜班小幫手：Firebase（Firestore）設定說明

完成後可以做到：設定自動記住並跨裝置共用、每個人儲存的數值互相讀得到、語音辨識照常可用。
全部步驟約 15 分鐘，使用免費的 Spark 方案即可。**請不要升級到 Blaze（付費）方案。**

> 提醒：資料會放在 Google 雲端。請先確認公司資安規定允許。

---

## 一、建立專案
1. 開啟 https://console.firebase.google.com ，用 Google 帳號登入。
2. 「建立專案」→ 取名（例如 night-inspection）→ Google Analytics 可以關閉 → 建立。

## 二、建立資料庫（Firestore）
1. 先確認你已經「進入專案」（網址長得像 `console.firebase.google.com/project/你的專案ID/...`，而不是專案清單頁）。
2. 找 Firestore 的方法（Firebase 改版後選單名稱常變，擇一即可）：
   - 左側選單找「建構（Build）」或「資料庫和儲存空間（Databases & Storage）」，展開後點「Firestore Database」。
   - 左側選單看不到時：先點左上角 ☰ 展開選單，或點「所有產品／產品類別」。
   - 直接用上方搜尋框輸入 `Firestore`。
   - 最快：把網址改成 `https://console.firebase.google.com/project/你的專案ID/firestore`（把「你的專案ID」換成你的專案 ID，專案 ID 在「專案設定」可以看到）。
3. 點「建立資料庫」。如果畫面要你選版本，選 **標準版（Standard edition）**，不要選企業版。
4. 位置選 **asia-east1（台灣）**。
5. 安全規則選 **「正式版模式」**（不要選測試模式）。
6. 建好後到「規則」分頁，把這包裡的 `firestore.rules` 內容整份貼上，按「發布」。

## 三、啟用登入
1. 左側找「Authentication」（可能在「建構」或「安全性」底下；找不到就用上方搜尋框輸入 `Authentication`，或網址改成 `https://console.firebase.google.com/project/你的專案ID/authentication`）→「開始使用」。
2. 「登入方式」→ 啟用 **「電子郵件／密碼」**（只開第一個，不要開「電子郵件連結」）。
3. 「使用者」分頁 →「新增使用者」：為你自己和每位同事各建一個帳號（Email 與密碼）。
   - Email 不一定要是真的信箱，但要記得，登入時要輸入。
   - 建好後，**複製你自己那一列的「使用者 UID」**，下一步要用。

## 四、指定管理者（只有管理者能改共用設定）
1. 回到「Firestore Database」→「資料」→「開始新增集合」。
2. 集合 ID 輸入 `admins` → 下一步。
3. 文件 ID 貼上**你的 UID**；欄位隨便填一個，例如 欄位 `role`，類型 string，值 `admin` → 儲存。
4. 要讓別人也能改設定，就再新增一份文件，文件 ID 是他的 UID。

## 五、取得連線設定
1. 專案總覽左上角齒輪 →「專案設定」→「一般」→ 往下到「你的應用程式」。
2. 點 `</>`（網頁）→ 取個暱稱 → 註冊應用程式（Firebase Hosting 不用勾）。
3. 畫面會出現一段 `const firebaseConfig = { ... }`，整段複製起來。

## 六、放進 App
擇一即可：
- **做法 A（建議）**：打開 `firebase-config.js`，把最後一行 `window.FIREBASE_CONFIG = null;` 換成
  `window.FIREBASE_CONFIG = { ...貼上大括號裡那些內容... };`，存檔後把整個資料夾重新上傳到 Netlify。大家就不用再貼。
- **做法 B**：在 App 的「⋯ 更多功能 → 📦 備份／同步」裡的「🔥 Firebase 設定」直接貼上整段，按「儲存設定」。**每台裝置都要貼一次。**

## 七、登入與第一次上傳設定
1. 在「📦 備份／同步」輸入 Email、密碼、顯示名稱 → 登入。
2. 狀態顯示「你可修改共用設定…」代表你是管理者。如果顯示「一般使用者」，請確認第四步的文件 ID 是否和畫面上的 UID 完全一樣。
3. 管理者第一次登入時，會自動把這台裝置目前的設定上傳成共用設定，並上傳最近的本機歷史紀錄。之後在 App 裡改設定，約 4 秒內自動上傳。
4. 同事登入後，會自動取得共用設定；他們儲存的紀錄，你在 App 裡的「歷史紀錄」就看得到，並標示名字，「前次值」也會用到他們的紀錄。

## 八、建議的安全設定
- Authentication →「設定」→「授權網域」：確認有你的 Netlify 網址。
- 不要把權限規則改成 `allow read, write: if true;`，那會讓任何人都能讀寫。
- 離職或不再使用的人，到 Authentication 把帳號停用或刪除。
- apiKey 出現在網頁裡是正常的，Firebase 靠「規則」和「登入」保護資料，不是靠藏金鑰。

## 九、費用
Spark 免費額度：每天約 5 萬次讀取、2 萬次寫入、1 GiB 儲存。數十人的巡檢用量遠低於上限。

## 常見問題
- **登入後顯示「沒有權限」或存不到雲端**：多半是規則沒發布，或帳號沒有登入；重新貼一次 `firestore.rules` 並發布。
- **看不到別人的紀錄**：確認大家連到同一個 Firebase 專案（設定相同），且都已登入。
- **App 一直顯示舊版**：手機關掉 App 重開兩次；或在 Safari 清除該網站資料後重新加入主畫面（注意：這會清掉這台裝置上還沒儲存的資料）。
- **claude.ai 連結的資料不會自動搬過來**：兩邊資料庫不同。要搬移請用「備份／同步」匯出再匯入。
