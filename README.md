# 夜班小幫手

夜班巡檢抄表用的 iPhone 網頁 App（PWA）。推到 GitHub 的 main 分支後，GitHub Pages 會自動部署（網址：https://king22killer-dot.github.io/-/）。

- 使用說明：App 內「⋯ 更多功能 → 📖 使用說明」
- Firebase 設定：`docs/Firebase設定說明.md`
- 給 Claude Code 的開發規則：`CLAUDE.md`

## 槽車入料小幫手

另一個獨立的 App，放在 `tank/` 資料夾：https://king22killer-dot.github.io/-/tank/ （用 Safari 開啟 → 分享 → 加入主畫面）。

## 停車費小幫手

另一個獨立的 App，放在 `parking/` 資料夾：https://king22killer-dot.github.io/-/parking/ （用 Safari 開啟 → 分享 → 加入主畫面）。一鍵查詢汽機車停車費與交通罰鍰，可以只選要查的縣市。按「一鍵查詢」會打開各縣市官方查詢網頁（車號自動複製），查到的欠費記下來後 App 幫你算總額、提醒繳費期限。
